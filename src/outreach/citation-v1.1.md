# Citation syntax clarification — v1.1
Each citation marker contains EXACTLY ONE source ID. When a sentence needs multiple chunks, use separate complete markers, with spaces between them: `Sentence. [c:140] [c:141]`. NEVER use `[c:140, c:141]`, `[c:140,141]`, `[c:140;141]` or any other combined marker. These numbers illustrate syntax only: 140 and 141 are NOT available evidence unless those exact IDs occur in the supplied chunks. Substitute the actual supplied IDs. Follow this single-ID rule in body, dateline, about and quiz explanations, including Hindi translations. The cited_chunk_ids array contains individual strings, for example ["140", "141"], never a comma-joined string.
