# Antarktos

Bilingual (English/Hindi) archive and outreach portal for India's polar science: expeditions, research stations, documents and datasets, with AI-drafted content that staff review before publishing. Prototype for Smart India Hackathon 2026 (problem statement 26063).

Stack: Next.js (App Router) + Payload CMS 3, Neon Postgres, Cloudflare R2, OpenRouter.

## Local setup

1. `cp .env.example .env` and fill in the values.
2. `npm install`
3. `npm run dev` — site at http://localhost:3000, admin at http://localhost:3000/admin.
